# Linux Markdown 作业

## 写作

- 先读题目、评分要求和用户提供的材料，逐项覆盖要求；不把过往作业的具体章节当作固定模板。
- 用中文写清楚的一级标题和分层小节；有身份信息要求时写姓名、学号，具体值以本次材料为准。
- 概念先用自己的话解释，再给与题目直接相关的例子。命令、路径和语法用行内代码，较长示例用标注语言的代码块；列表和表格只在有助于阅读时使用。
- 需要学习反思时，区分已掌握、尚不熟悉和实际练习过的内容。只写真实学习与操作，不把计划或示例说成已经完成。
- 完成后检查标题层级、代码围栏、链接、图片语法和文件名，并通读是否有重复或与题目无关的内容。
