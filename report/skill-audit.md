# 各版 Skill 审核

审核范围为 `skill/v1` 至 `skill/v13` 的文件头、版本差异和写作决策。13 版均通过 `skill-creator` 的格式校验；该校验不等于验证每份作业的事实正确性。

| 版本 | 本版可复用改进 | 审核结论 |
| --- | --- | --- |
| v1 | Markdown 结构、示例与学习反思 | 初版有效；尚未写课程标题及 PDF 交付 |
| v2 | 命令前置条件、截图和故障记录 | 在 v1 上增加实践证据 |
| v3 | 源码、汇编、寄存器和栈的推导 | 适用条件限定到当次架构 |
| v4 | 重新表述调度请求与切换 | 纠正把中断直接等同于调度的风险 |
| v5 | QEMU、GDB、启动镜像与符号核对 | 增加调试证据链 |
| v6 | API、ABI 和系统调用入口区分 | 减少由输出反推入口的错误 |
| v7 | 入口现场、退出检查与返回现场 | 区分服务函数返回和返回用户态 |
| v8 | 新任务创建与父子两条执行路径 | 不假定父子执行顺序 |
| v9 | ELF、链接和 exec | 区分装载、解释器与主程序入口 |
| v10 | 调度时机与上下文条件 | 修改旧规则，并限制源码检索结论 |
| v11 | 教材阅读、虚拟机与容器概念 | 标明未实践的验证方案 |
| v12 | 安全目标、访问控制与可信边界 | 限制单一机制的安全结论 |
| v13 | 受控安全实验与课程交付 | 补充当周标题、问题解决、Markdown/PDF 检查 |

旧版是迭代历史，不能要求它们预先包含第 12 周才出现的规则。按老师的七轮核心评分看，v1→v8 有连续、可辨认的变化；v9→v13 是之后的扩展。现有文件可审核文字内容，但原始 AI 生成、本人审阅、实际运行和历史时间分布仍需相应原始证据，不能由格式校验推定。
