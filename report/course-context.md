# 课程进程与 Skill 整理依据

本文件依据老师提供的《Linux内核原理与分析》教学进程整理，用于核对作业范围，不冒充学生当时的学习日志。

| 周次 | 教学进程中的重点 | 对应本项目 Skill |
| --- | --- | --- |
| 第 1 周 | 环境准备与 Linux 命令 | v1、v2 分别对应 Markdown 学习与命令实践，具体提交顺序以原作业为准 |
| 第 2 周 | 计算机如何工作，配套实验一 | v3 |
| 第 3 周 | 操作系统如何工作，配套实验二 | v4 |
| 第 4 周 | MenuOS 与启动分析，配套实验三 | v5 |
| 第 5 周 | 系统调用上篇，配套实验四 | v6 |
| 第 6 周 | 系统调用下篇，配套实验五 | v7 |
| 第 7 周 | 进程执行与切换，配套实验六 | v8 |
| 第 8 周 | 内核与系统的一般执行过程，配套实验七 | v9 |
| 第 9 周 | Linux 系统架构概览，配套实验八 | v10 |
| 第 10 周 | 教材第 10、11 章，虚拟化与容器 | v11 |
| 第 11 周 | 教材第 12 章，系统安全 | v12 |
| 第 12 周 | 选择一项 Linux 安全实验 | v13 |

教学进程对第 2 至 12 周作业的共同要求是：按“学号《Linux内核原理与分析》第X周作业”命名，以遇到的问题和解决方案为重点，结合该周教材及指定视频或实验，交 Markdown 和对应 PDF。第 10、11 周未列新的指定视频名称，作业中应如实说明实际学习材料。第 12 周要求安全类实验、两人一组且题目不能重复；是否满足组队与选题限制，需按课堂记录核对。
